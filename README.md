## 先搞清楚：你付的那笔钱买的到底是什么

CN2 GIA 是电信国际出口里的一条高档线路，自治域编号 AS4809。它贵不是因为带宽大，而是因为**优先级高、不轻易绕路、晚高峰不容易被挤**。

DMIT 官方的线路描述里，LAX 的 Premium 系列是这样走的：

- 电信去程走 CN2 GIA（AS4809）
- 联通去程直连 AS4837
- 移动去程经香港移动（AS58453）
- 三网回程统一走 CN2 GIA（AS4809）

回程走 GIA 才是关键。国内用户大多数时候是"下载"占主导，回程质量直接决定刷网页、拉文件、看视频的体验。很多便宜的"CN2"产品只在去程做了优化，回程照样走普通骨干网，价格差一半，体验也差一半。

> 一个容易被忽略的细节：AS4809 目前境内段的 IPv6 建设并不完整，Pro 系列的 IPv6 跨境段和境内段实际走 AS4134。所以别指望 CN2 GIA 的 IPv6 和 IPv4 一样快，主力还是用 IPv4。

## 从下单到开机，实际流程

1. **先测线路再下单。** DMIT 官方提供了 Looking Glass 和测试 IP，Telegram 社群和各类评测文里也都能查到。先 ping 一下、做一次路由追踪，比看十篇评测都实在。实际延迟受你所在地、运营商和机房当时负载影响，别人的 158ms 不等于你的 158ms。
2. **注册账号。** 邮箱务必填常用且能长期收信的，后续续费通知、工单回复都走它。
3. **选机房 → 选产品线 → 选配置。** 页面上的 Pro / EB / T1 分得很清楚，别在购物车里临时改主意。
4. **选付款周期。** TINY 和 Pocket 这类低配目前最低季付起。半年付、年付通常还能拿到额外流量或折扣，长期跑业务的话年付更划算。
5. **填优惠码并验证。** 见上一节。
6. **付款。** 支付宝、微信支付、PayPal 和主流信用卡都可以，国内用户付款没有障碍。
7. **等待开通。** 开通后先在控制面板里确认 IP、系统模板和流量额度，再开始迁移业务。

## 几个下单前值得知道的细节

**库存是动态的。** DMIT 的套餐经常发生售罄再补货的情况，尤其是低配和特价档。看到"缺货"不代表永久下架，但也别指望第二天一定补上。

**高防和额外 IP 是加购项，不含在套餐价里。** Premium Secure 系列在 CN2 GIA 基础上叠加了 DDoS 防护，价格和普通 Pro 不同，采购前要单独确认。

**IPv6 在 Pro 系列上不是主力。** 前面提过，境内段走的是 AS4134，速度上不要和 IPv4 一起期待。

**退款和换 IP 的规则，以服务条款和工单答复为准。** 不同产品线、不同时期的政策并不一致，第三方文章里写的具体天数经常是过期的。真在意这两项，下单前开一张工单问清楚，比事后补救省事。

## 常见问题

**CN2 GIA 和 CMIN2 到底选哪个？**
面向电信用户，GIA 延迟更低；移动、联通占比高的话，CMIN2 的均衡性更好。预算够就直接 Pro，预算紧就 EB，两者差距没有价格差距那么大。

**流量超了会被停机吗？**
不会。DMIT 的做法是降速继续用，4Mbps 到 10Mbps 不等，按套餐档次定。对低频访问的站点来说，这个限速档位基本够维持可用。

**年付一定更便宜吗？**
按单月均价算通常是，而且有时还能叠加 1.3 倍流量之类的活动。但 VPS 行业变化快，第一次买某个商家，用季付试一个周期再转年付，是更稳的做法。

**价格会不会再变？**
会。DMIT 从 AS3 到 AN5 平台迭代的过程中，洛杉矶 Pro 的入门年付就从 $88 调到过约 $119.99。上面所有价格都是整理时能够查到的报价，**最终以提交订单那一刻页面上显示的数字为准**。

选 CN2 GIA VPS 这件事，本质上不是挑最便宜的，而是想清楚你的访客从哪接入、能接受多少延迟、一个月跑多少流量。这三个问题有答案了，去 [👉 对比 DMIT 各机房当前套餐与库存](https://www.dmit.io/aff.php?aff=12046) 下单，比反复看评测快得多。
